## 📖 About The Project

**PRESTIGE** is a visually stunning, pixel-perfect landing page designed with a modern UI/UX approach. It focuses on clean design principles, smooth interactions, and a fully responsive layout that adapts seamlessly across all devices — from mobile phones to ultra-wide desktops.

### 🎯 Purpose

This project was built as a **practice project** to:

- Strengthen skills in **React component architecture**
- Master **Tailwind CSS** utility-first styling
- Leverage **Vite** for lightning-fast development
- Practice building **responsive** and **accessible** web interfaces
